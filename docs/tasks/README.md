# Rozsah budúcich úloh

Funkčná práca zatiaľ nie je rozdelená. Po dohode s Ľubom vytvor pre svoju úlohu samostatný súbor podľa `docs/TASK_TEMPLATE.md`.
Použi jedinečný názov, napr. `2026-11-20-aurora-nazov-ulohy.md` alebo `2026-11-20-claude-nazov-ulohy.md`.
Pred začiatkom skontroluj aj otvorené PR. Dokumenty nie sú automatický zámok súborov.
